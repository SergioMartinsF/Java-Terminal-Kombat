# 🥊 Ultra Emoji Combat

Simulador de lutas interativo desenvolvido em Java para o terminal, aplicando os pilares fundamentais da Programação Orientada a Objetos (POO).

## 🚀 Tecnologias e Conceitos Aplicados
- **Java:** Lógica principal e execução no terminal.
- **Classes e Objetos:** Molde de `lutador` para instanciar o elenco e classe `luta` para gerenciar as regras de combate.
- **Encapsulamento:** Atributos privados e métodos de acesso (Getters/Setters), incluindo validação automática de categoria com base no peso.
- **Estruturas de Dados:** Uso de Vetores (Arrays) para armazenamento e listagem do elenco.
- **Interatividade:** Uso da classe `Scanner` para entrada de dados do usuário com validação de loops `while` (prevenção de quebra do sistema).

## 🎮 Como executar
1. Compile os arquivos `.java` da pasta `ultraemojicombat`.
2. Execute a classe principal `ultraemojicombat`.
3. Siga as instruções no terminal para escolher o Desafiado e o Desafiante através de seus respectivos IDs numéricos.
